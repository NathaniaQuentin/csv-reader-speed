A faster drop-in replacement for make.fun's csv-reader 1.0.0: it answers exactly as the reference on every case — 6/6 practice cases and 6,122 fuzz inputs, 0 failures — and runs about 3.4x faster than the baseline on CPU time. Records with no quote are parsed with one slice and one split; only records that hold a quote go through the field-by-field reader, so the text is never built up character by character.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
